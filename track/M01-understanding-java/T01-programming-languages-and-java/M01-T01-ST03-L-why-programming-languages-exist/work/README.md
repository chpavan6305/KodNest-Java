## Why Programming Languages Exist

### Why does a computer need instructions?
A computer needs instructions because it cannot think or make decisions on its own. It only performs tasks based on the instructions given by the programmer.

### Why can we not build applications using normal human language?
Human language is ambiguous and can have multiple meanings, while computers require clear and precise instructions.

### What problem do programming languages solve?
Programming languages help humans communicate with computers in a simple and understandable way.

### Why is machine language difficult for humans?
Machine language is difficult because it consists of binary numbers (0s and 1s), which are hard to read, write, and debug.

### How does Java help?
Java provides simple syntax, readability, portability, and powerful libraries that make application development easier.
